# Control Tower Dashboard

## Цель проекта
Демонстрационный аналитический дашборд для презентации руководителю. Показывает,
как на базе shadcn/ui можно построить наглядный отчёт с ключевыми метриками.
Это пример/прототип, не production-система — данные могут быть mock.

## Аудитория
Руководитель (не техническая аудитория) — акцент на ясности, а не на полноте
данных. Один "золотой путь" экрана важнее, чем десяток недоработанных.

## Стек (план)
- Next.js
- shadcn/ui (компоненты, включая `Chart` — обёртка над Recharts)
