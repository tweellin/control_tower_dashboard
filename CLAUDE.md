# Control Tower Dashboard

## Цель проекта
Демонстрационный аналитический дашборд для презентации руководителю. Показывает,
как на базе shadcn/ui можно построить наглядный отчёт с ключевыми метриками.
Это пример/прототип, не production-система — данные могут быть mock.

## Аудитория
Руководитель (не техническая аудитория) — акцент на ясности, а не на полноте
данных. Один "золотой путь" экрана важнее, чем десяток недоработанных.

## Стек
- Next.js 16 (App Router, TypeScript, Tailwind v4), в `src/`
- shadcn/ui (Card, Chart — обёртка над Recharts, Badge, Separator, Button)
- next-themes — переключатель light/dark (кнопка в шапке), тёмная тема по
  умолчанию (`defaultTheme="dark"`, без auto-detect системной темы)
- Фирменные шрифты X5 (`next/font/local`) и палитра X5 — см. раздел
  "Брендинг" ниже
- Mock-данные: сгенерированный JSON, см. [data/mock-metrics.json](./data/mock-metrics.json)
- Запуск: `npm run dev` (нужен Node.js LTS, поставлен через `winget install OpenJS.NodeJS.LTS`)

## Брендинг
Источники — папка `design_sources/` (не удалять, это исходники бренда):
- `design_sources/fonts/` — шрифты X5 Sans UI (Regular/Medium/Bold, для UI/
  текста) и X5 Sans (Light/Regular/Medium/Bold, для заголовков и крупных
  чисел). Скопированы в `src/fonts/`, подключены в `src/app/layout.tsx`
  через `next/font/local` как `--font-x5-sans-ui` (`font-sans`) и
  `--font-x5-sans` (`font-heading`).
- `design_sources/pallete/palette-x5.json` / `.md` — палитра X5 (accent —
  зелёная шкала 5–100, grey — шкала 5–100, white). Все токены темы
  (`src/app/globals.css`) переопределены на эту палитру для light и dark;
  исходные CSS-переменные бренда (`--accent-x5-*`, `--grey-*`) объявлены
  в `:root` как основа.
- `design_sources/images/rvi_logo.png` (лого "X5 Import", чёрный wordmark
  на прозрачном фоне) — скопирован в `public/rvi-logo.png`, выводится в
  шапке дашборда внутри белой плашки (`src/components/brand-logo.tsx`),
  т.к. тёмная тема иначе съедает чёрный текст логотипа.
- Стиль — тёмный "futuristic AI / control room" по умолчанию: почти
  чёрный фон (`#1c1f1f`), карточки — приподнятая grey/90 поверхность с
  тонкой зелёной линией-акцентом сверху и glow-тенью при hover, радиальное
  зелёное свечение и едва заметная сетка на фоне страницы, пульсирующий
  индикатор "Обновлено {дата}" в шапке. Светлая тема — та же система
  токенов, but на белом/grey-5 фоне (не нейтральная дефолтная тема shadcn).
- Цвета графиков (см. `src/components/metric-chart-card.tsx`,
  `--chart-1..4` в globals.css): вместо категориальной 3-цветной схемы из
  skill `dataviz` использована brand-специфичная **sequential + hero**
  схема, т.к. фирменная палитра содержит только один акцентный оттенок
  (зелёный) + серую шкалу: 2024 — тусклый серый (наименее важный, самый
  старый), 2025 — светлее/темнее серый (в зависимости от темы, шаг к
  "сейчас"), 2026 — фирменный зелёный accent/90 с glow-эффектом (герой
  графика, текущий год), Цель 2026 — пунктирная нейтральная линия
  (не самостоятельный ряд, а референс). Идентичность рядов не зависит
  только от оттенка (есть направление яркости + пунктир у цели + легенда),
  что не хуже по доступности, чем произвольная категориальная палитра.

## Метрики
См. [METRICS.md](./METRICS.md) — полный список метрик (8 шт., все включены
в дашборд) и формат визуализации.

## Решения и почему
- Набор метрик: все 8 метрик (SL ФРОВ, SL неФРОВ, SLT Поставщик-ХАБ,
  SLT ХАБ-РЦ, Оборачиваемость складских остатков, Средний LT, STD LT,
  Утилизация инфраструктуры) включены в дашборд без отбора — пользователь
  считает их все важными для руководителя.
- Визуализация: единый тип для всех метрик — линейный график с 4 линиями
  (2024, 2025, 2026, Цель 2026), без разделения по типам (тренд/сравнение/
  структура). Даёт единообразие восприятия для нетехнической аудитории.
- Расшифровка сокращений (ФРОВ, SLT, LT, ХАБ, РЦ) сознательно не
  документируется — аудитория (руководитель) уже владеет терминологией.
- Mock-данные сгенерированы (не захардкожены вручную) по диапазонам,
  заданным пользователем для 2026, с направлением "лучше" (больше/меньше)
  на метрику. 2024 и 2025 сдвинуты в худшую сторону от 2026, Цель 2026 —
  константа чуть лучше диапазона 2026. Детали и диапазоны — см.
  [METRICS.md](./METRICS.md#mock-данные), сами данные —
  [data/mock-metrics.json](./data/mock-metrics.json).
- Разделы экрана: метрики сгруппированы в 3 блока — Сервис, Логистика,
  Инфраструктура (задано пользователем по каждой метрике отдельно, не
  выведено автоматически). Порядок вывода — см. [METRICS.md](./METRICS.md#разделы-дашборда).
- Компоновка карточки метрики: название + текущее значение (последний
  доступный месяц 2026) + дельта к тому же месяцу 2025 (иконка направления
  ↑/↓ по факту знака, цвет — зелёный/красный в зависимости от того, хорошо
  это или плохо для конкретной метрики) + линейный график ниже.
- Цветовая палитра графиков строилась по методике skill `dataviz` (форма →
  цвет → маркеры → интерактив → доступность), но адаптирована под
  фирменную палитру X5 (моно-серый + один зелёный акцент) — см. раздел
  "Брендинг" выше.
- Маркеры на линии "2026": заливка = цвет серии (зелёный) + 2px кольцо в
  цвет поверхности карточки (не белая заливка по умолчанию от recharts —
  на светлой теме это выглядело как "пунктир", проедающий линию).
- Next.js разворачивался через `create-next-app` во временную директорию
  (в целевой папке уже были CLAUDE.md/METRICS.md/data — create-next-app не
  работает в непустой директории), затем файлы перенесены с сохранением
  существующих.
